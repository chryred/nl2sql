# Task Completion Checklist

After completing a coding task:

1. **Build**: `npm run build` - ensure TypeScript compiles without errors
2. **Lint**: `npm run lint` - check for style violations
3. **Test**: `npm test` - run unit tests
4. **README**: Update README.md if user-facing changes (per CLAUDE.md: "변경사항 현행화")
5. **MCP docs**: Update `.claude/rules/mcp.md` if MCP tools changed
